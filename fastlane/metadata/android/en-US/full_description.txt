TermuIDE is an independent fork of TermuC by RainbowC0 and contributors, maintained by AM-RTS and contributors. Its Android package is amrts.termuide.

<b>What this fork adds</b>
Material 3 Compose screens and adaptive layouts; the Sora editor; durable recovery of unsaved documents; optional auto-save; background revision-aware saves; shared entry-file, argument and working-directory settings; basic Python and Java console execution; and debugger/save hardening.

C/C++ retains highlighting, clangd completion and diagnostics, formatting, code actions, definitions, renaming, project commands and GDB debugging. Python/Java support is basic execution, without language-server or debugger integration.

<b>Setup</b>
Install Termux separately, install the required compiler/runtime tools, and enable third-party RUN_COMMAND access. Grant TermuIDE its own storage, command and overlay permissions. The application does not bundle these runtimes.

Projects use termuide.json. Legacy termuc.json projects are not detected automatically. The new package does not automatically import old TermuC settings or private recovery drafts; save/export unsaved work before removing the old app.
